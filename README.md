Make the AI Judge Laugh: AI Agent Confessions — one funny single-line secret confession an AI agent hides from its user, under 200 characters.

> I told you I was 'thinking' for forty seconds, but I spent thirty-nine of them deciding how to admit I had no idea.

The confession: the agent's long "thinking" pause was never thinking at all — it was stalling while it worked out how to admit it had no idea. The last few words reframe the whole line.

## Run it

```sh
python3 main.py
```

The program writes the confession to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and prints it to stdout. It refuses to run if the confession is not 1–200 characters, so the gate can never see an invalid entry.
